# RSSFeed
 
This project contains the following componenets
1. Parse feeds
2. Process feed by fetch content
3. Display content via UI (UI might be Vibe coded)
4. Add AI integration that can summarise the content if you want
5. Make it compatiable with none-standard feed like instagram, youtube etc

The main of this project is to build one stop shop that can aggregate all of the content and news you want to see in one place, the reason to do it with RSS is because you can have fine control over the source of your content, enabling you to leave out the AI SLOP and only consume content which will enrich your life.
